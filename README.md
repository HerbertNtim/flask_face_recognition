# 🧠 Face Recognition & Gender Prediction Web App

A Flask-based Machine Learning web application that performs **face recognition** and **gender prediction** using computer vision techniques. The system allows users to upload images and receive predictions through a simple and interactive web interface.

---

## 🚀 Features

- 📸 Face detection from images
- 🧑‍🤝‍🧑 Face recognition (identify individuals)
- ⚧ Gender prediction
- 📂 Image upload support (.jpg, .jpeg, .png, .webp)
- 🖥️ Web-based interface using Flask
- 🎨 Clean UI built with Bootstrap

---

## 🏗️ Tech Stack

- **Backend:** Flask (Python)
- **Machine Learning / CV:** OpenCV, NumPy
- **Frontend:** HTML, Bootstrap
- **Visualization:** Matplotlib (optional)
- **Model:** Custom face recognition pipeline
